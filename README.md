# Tab Proc - CSV Statistics Processing

A practice project for learning pandas data manipulation and statistical analysis with CSV files.

## Introduction

This project contains Python scripts that demonstrate how to read CSV files, calculate statistical measures (mean, standard deviation, minimum, maximum, sum), and save the results to output files. It's designed as a learning exercise for working with pandas DataFrames and performing basic data analysis tasks.

## Installation

### Prerequisites

- Python 3.7 or higher
- pip package manager

### Required Packages

Install the required Python packages using pip:

```bash
pip install pandas
```

For data visualization (optional):

```bash
pip install matplotlib
```

### Setup

1. Clone or download this repository
2. Navigate to the project directory
3. Install dependencies as shown above
4. Ensure you have an `input.csv` file in the project directory

## Files Description

### Script Files

- **gen_sample.py**: Generates sample CSV data for testing purposes
- **tab_stat.py**: Comprehensive statistics calculator that reads input.csv and processes data with multiple statistical operations, saving results to output.csv
- **tab_stat2.py**: Simplified statistics calculator that computes mean, std, min, max, and sum for columns B-F, appending results as new rows (101-105) to output2.csv

### Data Files

- **input.csv**: Input data file containing a table with 100 rows and 6 columns (A through F)

  - Column A: ID column (identifier)
  - Columns B-F: Numeric data for statistical analysis

- **output.csv**: Output file generated by tab_stat.py containing processed results
- **output2.csv**: Output file generated by tab_stat2.py containing original data plus statistical summary rows

## Usage

### Running tab_stat2.py

The simplest way to calculate statistics:

```bash
python tab_stat2.py
```

This script will:

1. Read all data from input.csv
2. Calculate statistics for columns B through F
3. Append 5 new rows (101-105) with the following statistics:
   - Row 101: Average (AVR)
   - Row 102: Standard Deviation (STD)
   - Row 103: Minimum (MIN)
   - Row 104: Maximum (MAX)
   - Row 105: Sum (SUM)
4. Save results to output2.csv
5. Display the last 10 rows in the console

### Running tab_stat.py

For more detailed processing:

```bash
python tab_stat.py
```

This script performs multiple stages of data processing and saves intermediate results to output.csv.

### Generating Sample Data

If you need to create test data:

```bash
python gen_sample.py
```

## Expected Input Format

The input.csv file should have the following structure:

```
A,B,C,D,E,F
ID1,10,20,30,40,50
ID2,15,25,35,45,55
...
ID100,12,22,32,42,52
```

- Column A: Text or ID values
- Columns B-F: Numeric values for statistical calculations

## Expected Output Format (output2.csv)

After running tab_stat2.py, the output will contain:

```
A,B,C,D,E,F
ID1,10,20,30,40,50
...
ID100,12,22,32,42,52
AVR,15.5,25.5,35.5,45.5,55.5
STD,2.1,2.1,2.1,2.1,2.1
MIN,8,18,28,38,48
MAX,20,30,40,50,60
SUM,1550,2550,3550,4550,5550
```
